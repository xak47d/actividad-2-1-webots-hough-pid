# Actividad 2.1 - Webots Lane Detection with Hough + PID

This repository contains the implementation and deliverables for a Webots activity focused on lane detection using OpenCV and steering control using a PID controller.

## Contents

- `symple_controller_act_2_1.py`
  Python external controller for Webots.
- `city_2023b.wbt`
  Webots world derived from the stock `city.wbt` sample.
- `run_webots_controller.sh`
  Helper script to run the controller with the expected Webots Python environment.
- `requirements_webots.txt`
  Minimal Python dependencies.
- `Actividad_2_1_Entrega.md`
  Main write-up for the assignment.
- `Actividad_2_1_Validacion_Latest.md`
  Latest automatic validation summary generated by the controller.
- `Actividad_2_1_Deteccion_de_Carriles_EquipoXX.pdf`
  Generated PDF deliverable snapshot.
- `build_activity_2_1_report.py`
  Report generation helper.
- `Actividad 2.1 - Detección de carriles usando transformada de Hough.md`
  Original activity note used as source material.

## What the controller does

The controller implements the requested perception pipeline:

1. On-board camera capture
2. Grayscale conversion
3. Canny edge detection
4. Region of interest with `fillPoly`
5. `HoughLinesP` segment detection
6. Filtering of mostly horizontal segments
7. Smallest horizontal midpoint error selection
8. PID steering output

It also includes:

- steering smoothing
- temporary guidance retention when the line is briefly lost
- automatic validation reporting per run
- dual display support in the world:
  - raw camera image
  - processed detection preview

## Running

Open `city_2023b.wbt` in Webots and then run:

```bash
./run_webots_controller.sh
```
